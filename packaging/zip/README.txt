LedgerFlow — ZIP distribution
================================


ENGLISH
-------

Installation:

    bash install.sh

LedgerFlow will be installed only for the current user.
Administrator permissions are not required.

After installation, open the application menu and search for:

    LedgerFlow

You can also start it from a terminal:

    ledgerflow

Uninstallation:

    ~/.local/opt/ledgerflow/uninstall.sh


ESPAÑOL
-------

Instalación:

    bash install.sh

LedgerFlow se instalará únicamente para el usuario actual.
No necesita permisos de administrador.

Después de instalarlo, abre el menú de aplicaciones y busca:

    LedgerFlow

También puedes iniciarlo desde una terminal:

    ledgerflow

Desinstalación:

    ~/.local/opt/ledgerflow/uninstall.sh
